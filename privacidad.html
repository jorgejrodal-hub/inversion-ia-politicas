Política de privacidad

Última actualización: 11 de noviembre de 2026.

Esta aplicación es una herramienta privada de automatización para una única cuenta autorizada. No permite el registro de usuarios externos ni comercializa información.

Acceso a datos de Google

Tras el consentimiento OAuth, la aplicación utiliza Google Drive para crear y almacenar archivos de datos financieros y manifiestos de integridad en una carpeta de trabajo de la cuenta autorizada. Según el permiso OAuth que se configure finalmente, Google podría otorgar un alcance más amplio que el uso efectivo previsto. El objetivo operativo de la aplicación es escribir en la carpeta designada, no examinar otros archivos.

Almacenamiento y proveedores

Los archivos financieros se almacenan de forma privada en la cuenta Google Drive autorizada. La automatización se ejecuta en GitHub Actions y consulta una fuente externa de datos financieros. Las credenciales de acceso se configuran mediante secretos del entorno de ejecución y no se publican en este sitio. Google y GitHub procesan los datos técnicos necesarios para prestar sus respectivos servicios.

Uso, conservación y divulgación

La información se utiliza exclusivamente para la gestión, revisión y auditoría personales de datos financieros. Los archivos permanecen hasta que la persona titular los elimine. La aplicación no vende datos de Google ni los difunde públicamente. Los permisos de acceso pueden revocarse desde la configuración de seguridad de la cuenta de Google.

Contacto

Para cuestiones relacionadas con esta aplicación personal, utiliza los datos de contacto que figuran en la pantalla de autorización de Google.
