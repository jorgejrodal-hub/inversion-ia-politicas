Automatización personal de datos financieros

Aplicación de uso personal para consultar datos financieros de un proveedor externo y almacenar copias de trabajo en una carpeta autorizada de Google Drive.

La ejecución se realiza mediante tareas programadas. No se ofrece como servicio público ni permite que visitantes de esta página accedan a Google Drive.

La autorización de Google se utiliza para crear archivos derivados de las descargas en la cuenta expresamente autorizada. Esta página no solicita credenciales ni recibe archivos.
